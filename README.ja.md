# Doodle Font

**自分で描いた文字をフォントにできるWindowsアプリです。**

手書き文字や小さな絵文字を描き、文章で見え方を確かめて、自分だけのフォントとして書き出せます。基本の編集と書き出しは、AIなしでも使えます。

[한국어](README.md) · [English](README.en.md) · **日本語**

[ダウンロード](https://github.com/pnpcrow/doodle-font/releases/latest) · [リリース情報（韓国語）](https://github.com/pnpcrow/doodle-font/releases/tag/v0.1.0) · [不具合の報告](https://github.com/pnpcrow/doodle-font/issues)

## はじめに

1. [最新リリース](https://github.com/pnpcrow/doodle-font/releases/latest)から **Doodle-Font-0.1.0-windows-x64.zip** をダウンロードします。
2. ZIPをすべて展開し、**Doodle-Font.exe** を実行します。インストーラーは不要です。
3. **設定 → 表示言語**で韓国語・English・日本語を選びます。初期設定ではシステムの言語に従います。

**動作環境：** Windows 10/11、64ビット（x64）、OpenGLに対応したグラフィックスドライバー。現在のバージョンは **0.1.0** です。

## できること

| 機能 | 内容 |
| --- | --- |
| 文字を描く | ペン・図形・色・レイヤーで描いたり、PNG/JPEG画像を読み込んだりできます。 |
| さまざまな文字を使う | ハングル・ラテン文字・かな・漢字・記号を選ぶほか、文章に含まれる文字だけを追加できます。 |
| 文章で確認する | 作った文字を並べて、形や文字間隔を確認できます。 |
| テンプレートを使う | テンプレートから作り始め、必要に応じて元の絵に戻せます。 |
| フォントを書き出す | パソコン向けの **TTF・OTF**、Web向けの **WOFF2・WOFF** で保存できます。 |

カラーの文字も作れます。カラーや特殊な文字の組み合わせの表示は、フォントを使うアプリによって異なります。

## 最初のフォントを作る

1. **プロジェクト**でプロジェクト名とフォントファミリー名を決めます。
2. **描く**で文字を選び、キャンバスに描きます。
3. **文章プレビュー**で、作った文字を並べて確認します。
4. **フォントを書き出す**で形式を選び、検査してから保存します。Windowsにインストールする場合は、TTFまたはOTFを選んでください。

## AIは必要なときに

**設定 → AIアシスト**で選択できます。初期設定ではオフになっています。

| 選択肢 | 使い方 |
| --- | --- |
| 使わない | 自分で描いてフォントを書き出します。 |
| ローカルAI | 初めて選択するとモデルを自動でインストールします（約3.4GBのダウンロード）。インストール後は、インターネット接続やAPIキーなしで使えます。 |
| OpenAI互換 / Anthropic互換 | 利用するサービスのAPIアドレス・モデル名・キーを入力します。インターネット接続が必要で、サービスの利用料金がかかる場合があります。 |

絵について相談したり、新しい候補を作ったりできます。候補は現在の絵と比べてから、**この候補を採用**で適用します。絵をAPIへ送信するかどうかは別途選択でき、APIキーは現在のWindowsアカウントを使って暗号化して保存します。

## 作業の保存と画面設定

作業はこのPCに自動保存されます。別の場所に保管したり移したりするときは、**プロジェクト → プロジェクトのコピーを保存**を使ってください。標準の保存先は `%LOCALAPPDATA%/DoodleFont` です。

設定で表示言語やライト・ダークテーマを変更できます。コンパニオンはドラッグで移動でき、右クリックでオプションを開けます。入力パネルが絵に重なるときは折りたたみ、画面下のステータスバーから開き直せます。

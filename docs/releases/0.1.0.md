# 두들 폰트 · Doodle Font 0.1.0

Windows에서 나만의 글자와 그림문자를 그려 폰트로 내보내는 Rust 네이티브 앱의 첫 공개 릴리스입니다.

## 다운로드와 실행

1. [릴리스의 Assets](https://github.com/pnpcrow/doodle-font/releases/tag/v0.1.0)에서 **Doodle-Font-0.1.0-windows-x64.zip**을 내려받습니다.
2. 압축을 모두 풀고 **Doodle-Font.exe**를 실행합니다. 별도 설치 과정은 없습니다.
3. **설정 → 표시 언어**에서 한국어·English·日本語 또는 시스템 설정을 선택할 수 있습니다.

Windows 10/11 x64와 OpenGL을 지원하는 그래픽 드라이버가 필요합니다. ZIP에는 실행 파일, 사용 안내, AI 설치 목록·스크립트, 타사 라이선스가 포함됩니다. `SHA256SUMS.txt`는 ZIP 파일의 SHA256이며, ZIP 안의 `SHA256.txt`는 실행 파일의 SHA256입니다. GitHub가 별도로 제공하는 Source code 압축 파일은 개발용 소스입니다.

## 주요 기능

- 펜·도형·이미지·레이어로 글리프 편집, 문자와 문자열 매핑, 한글·라틴·가나·한자·기호 탐색.
- 문장 미리보기, 템플릿 적용과 원본 복원, 프로젝트 자동 저장과 사본 저장.
- TTF·OTF·WOFF·WOFF2 내보내기와 출력 전 검사.
- 선택적으로 사용하는 로컬 AI 및 OpenAI·Anthropic 호환 API 상담·후보 생성. 결과는 비교한 뒤 직접 채택합니다.
- 작업 영역을 유지하는 접이식 플로팅 입력창과 드래그로 옮길 수 있는 애니메이션 컴패니언.
- 한국어·영어·일본어 화면, 라이트·다크 테마, 통합 제목 표시줄과 공통 앱 아이콘.

## AI와 저장 위치

AI 없이도 편집과 폰트 내보내기를 사용할 수 있습니다. **설정 → AI 어시스트 → 로컬 AI**를 처음 선택하면 Gemma 4 E2B 모델과 실행기를 별도로 내려받습니다(약 3.4GB). 설치가 끝나면 인터넷이나 API 키 없이 로컬 AI를 사용할 수 있습니다. 입력 판단 AI는 별도 선택 옵션입니다. 모델 파일과 개인 API 키는 배포 ZIP에 포함하지 않습니다.

프로젝트와 환경설정은 `%LOCALAPPDATA%/DoodleFont`에 저장합니다. 기존 사용자는 같은 Windows 계정에서 새 실행 파일을 실행하면 기존 작업과 설정을 이어서 사용합니다. 자세한 사용법은 [프로젝트 안내](https://github.com/pnpcrow/doodle-font#readme)를 참고하세요.

## 검증 범위

이 릴리스의 실행 파일은 자동 테스트 **102개**, 네이티브 UI **24개 시나리오**, 전체 대상의 정적 검사를 통과한 0.1.0 빌드입니다. 표시 언어 변경·재실행, 작은 창의 설정·내보내기, 폰트 출력과 앱 아이콘을 확인했습니다. 세부 범위는 [검증 기록](https://github.com/pnpcrow/doodle-font/blob/v0.1.0/docs/VALIDATION.md)에 있습니다.

AI 생성 품질과 외부 프로그램의 컬러 폰트·문자열 매핑 지원은 모델과 사용 환경에 따라 달라집니다. 사용한 자형의 출처와 이용 조건은 후보 및 출력 보고서에서 확인할 수 있습니다.

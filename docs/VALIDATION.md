# 검증 기록 · 2026-10-10

Windows x64, AMD Radeon 780M, 약 52GiB 시스템 RAM. Rust 1.98.1 MSVC. 앱은 egui/eframe 네이티브 화면이며 WebView·Node·Python을 사용하지 않는다.

- 도메인/출력 16개, AI 연결/이미지/취소/잘못된 도형 응답 8개 테스트 통과.
- `cargo clippy --all-targets --locked -- -D warnings` 통과.
- UI QA 10개 화면을 실제 GPU에서 렌더링. 포인터 그리기·실행 취소·다시 실행·원본 보존·디스크 저장, AI 작업 중 포인터/편집 명령 차단 및 오류 후 편집 복귀 검증.
- 독립적인 Python fontTools에서 단색·COLR/CPAL·sbix·53,157 출력 글리프 TTF의 모든 테이블을 읽고 재저장/재파싱 통과. Python은 개발 검증에만 사용.
- 53,156개의 빈 작업 글리프(한글 + 한국/일본 한자) 자료: 생성 74.1ms, 폰트 출력 72.3ms, 896,112바이트. 부하 자료는 복잡한 도형이나 이미지가 없는 폭/지역별 자형 검증용이며 일반 작업 속도의 보장은 아니다.
- llama.cpp b11531 + EmbeddingGemma 2 Q8 실제 멀티모달 입력에서 768차원 벡터 확인. 웃는 얼굴에 대한 템플릿 유사도는 미소 0.78, 마음 0.66, A 0.65 순이었다.
- Gemma 4 E2B Q4가 같은 PNG를 보고 황토색 얼굴과 검은 눈/입을 한국어로 설명. 구조가 제한된 JSON으로 편집 가능한 컬러 얼굴 후보 생성도 확인. 생성 품질은 모델에 따라 달라지며 결과는 반드시 후보로 검토한다.
- 로컬 추론은 CPU 6스레드/8K 문맥으로 확인. 다른 빌드 작업과 함께 실행한 최초 상담은 약 65초, 구조를 제한한 벡터 후보는 약 60초였다. 추론 프로세스는 작업 종료 후 사라짐을 확인했다.

생성 자료는 `.gitignore`의 `artifacts/`에 보관한다. 화면은 `qa-ai-ready.png`, `qa-ai-busy.png`, `qa-ai-recover.png`에서 확인할 수 있다. 모델 가중치는 `%LOCALAPPDATA%/DoodleFont/ai`에 사전 설치했고 저장소에는 넣지 않았다. 설치 스크립트에는 원본 리비전, 배포 URL, SHA256을 고정했다.

외부 API는 실제 키 없이 모의 서버로 계약을 검증했다. 외부 앱의 색상/문자열 치환/지역별 자형 지원은 해당 앱의 폰트 엔진에 따라 달라진다. 앱은 GPU 추론 성능이나 모든 외부 앱의 이모지 교체를 보장하지 않는다.

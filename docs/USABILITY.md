# 사용성 개선 · 0.1.0

## 요구사항과 구현

1. 정돈된 화면과 시스템/라이트/다크: 두 개였던 왼쪽 열을 문자 선택 패널 하나로 합치고 문자 모음은 선택 메뉴로 이동했다. 새로/열기/사본 저장은 프로젝트 메뉴, 상세 레이어/복원/부품은 필요할 때 여는 속성 패널에 둔다. 양쪽 테마는 동일한 간격과 타이포그래피를 사용하고, egui-winit의 Windows ThemeChanged 경로로 시스템 테마를 반영한다. 그림 데이터와 펜 색은 테마를 바꿔도 변경하지 않는다.
2. 버튼 크기: egui 기본 hovered/active WidgetVisuals.expansion=1을 제거했다. hover/focus/press/selected 상태에서 실제 버튼의 hit rect와 배경 shape rect가 같은지 양쪽 테마에서 검사한다.
3. 어시스트 컴패니언: 생성 이미지의 눈 분리 레이어를 실행 파일에 포함한다. 실제 요청의 처리/성공/실패/취소와 캐릭터 상태를 연결했다. 그림 상담과 후보 만들기, 스크롤, 접기, 처리 중 입력 잠금은 유지한다.
4. 캐릭터 지침: 지정한 ChatGPT 프로젝트의 「지침 수정 검토」 대화에 있는 Minimal Bot Icon Converter v2.0을 읽었다. 캡슐 눈 두 개, 입/코/눈썹 없음, 둥근 얼굴과 작은 홍조, 단순한 색면과 시계 방향 기울기를 적용했다. 투명한 전체 실루엣은 앱의 움직이는 캐릭터에 맞춘 구도 변경이다. 원본 생성과 레이어 분리 프롬프트는 assets/companion/README.md에 기록한다.
5. 부드러운 움직임: Coucou 08393b657c79e99382eaf15185f480e6745997b0의 BotEngine.swift를 읽고 시간 기반 보간, 호흡, 시선, 눈 깜박임, 완료 반응의 접근을 참고했다. 기존 캐릭터/소리 자산과 코드를 복제하지 않았다. 16ms 갱신 요청과 프레임 속도와 독립적인 보간을 사용하며, 움직임 줄이기와 비활성 창에서는 반복 갱신을 요청하지 않는다.

## Needle 검토

새 요청을 빠르게 시작하는 한국어 예시 세 가지를 어시스트에 추가했다. 이들은 실행 권한을 확대하지 않고 기존 공통 AI 경로로 전달하며 사용자 확인 후 전송한다. Needle의 기본 한국어 판단 편차가 확인된 상태에서 새 함수를 늘리는 것은 이 작업에 필요하지 않아 도구 스키마는 유지했다. 낮은 신뢰도/복합 요청은 선택한 생성 AI로 원문을 전달하는 기존 방식이 계속 적용된다.

## 확인 방법

- `cargo test --locked`: 기존 폰트/AI 검사와 테마 설정의 저장/재실행, OS 테마 변경, 버튼 실제 도형과 클릭 영역의 불변성, 30/60/120fps 운동 비교, 눈 깜박임과 움직임 줄이기 검사.
- `pwsh -File scripts/ui-qa.ps1`: 기존 편집/후보/저장/설정/플로팅/내보내기와 라이트/다크 작은 창, 실제 테마 버튼 클릭, 새 프로세스 설정 복원.
- `pwsh -File scripts/ui-qa.ps1 -UsabilityOnly`: 사용성 관련 화면만 빠르게 확인.
- `cargo run --locked --features ui-qa --bin verify_companion -- artifacts/companion-motion`: 제품의 이미지와 눈 리그를 실제 GPU로 렌더링한 180개 프레임. 재현 가능한 60Hz 시계로 네 가지 상태와 눈 깜박임을 기록하며 실행 성능 벤치마크를 대신하지 않는다.

완성된 캐릭터 그림은 paint()에서 body.png와 두 캡슐 눈을 합성한다. body.png만 열면 눈이 없는 것이 정상이다. 테스트 캡처와 AI 모의 응답은 사용자 작업/키 저장소와 분리된 DOODLE_DATA_DIR에 보관한다. 버전은 0.1.0으로 고정한다.

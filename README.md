# 두들 폰트 · Doodle Font

**내 손으로 그린 글자를 폰트로 만드는 Windows 앱입니다.**

손글씨부터 작은 그림문자까지, 글자를 그리고 문장으로 확인한 뒤 나만의 폰트로 내보내세요. AI 없이도 모든 기본 편집과 내보내기를 사용할 수 있습니다.

**한국어** · [English](README.en.md) · [日本語](README.ja.md)

[다운로드](https://github.com/pnpcrow/doodle-font/releases/latest) · [릴리스 안내](https://github.com/pnpcrow/doodle-font/releases/tag/v0.1.0) · [문제 제보](https://github.com/pnpcrow/doodle-font/issues)

## 시작하기

1. [최신 릴리스](https://github.com/pnpcrow/doodle-font/releases/latest)에서 **Doodle-Font-0.1.0-windows-x64.zip**을 내려받습니다.
2. 압축을 모두 풀고 **Doodle-Font.exe**를 실행합니다. 별도 설치 과정은 없습니다.
3. **설정 → 표시 언어**에서 한국어·English·日本語를 선택합니다. 기본값은 시스템 언어입니다.

**지원 환경:** Windows 10/11, 64비트(x64), OpenGL을 지원하는 그래픽 드라이버. 현재 버전은 **0.1.0**입니다.

## 무엇을 만들 수 있나요?

| 기능 | 할 수 있는 일 |
| --- | --- |
| 글자 그리기 | 펜·도형·색상·레이어로 그리고 PNG/JPEG 이미지를 가져옵니다. |
| 여러 문자 사용 | 한글·라틴 문자·가나·한자·기호를 고르거나 문장에서 필요한 글자만 추가합니다. |
| 문장 미리보기 | 만든 글자를 문장에 넣어 모양과 간격을 확인합니다. |
| 템플릿 활용 | 템플릿으로 시작하고 필요하면 원본으로 되돌립니다. |
| 폰트 내보내기 | 컴퓨터용 **TTF·OTF**, 웹용 **WOFF2·WOFF**로 저장합니다. |

컬러 글자도 만들 수 있습니다. 컬러와 특수 문자 조합의 표시 방식은 폰트를 사용하는 프로그램에 따라 달라질 수 있습니다.

## 첫 폰트 만들기

1. **프로젝트**에서 프로젝트 이름과 폰트 패밀리 이름을 정합니다.
2. **그리기**에서 글자를 선택하고 캔버스에 그립니다.
3. **문장 미리보기**에서 직접 만든 글자가 어울리는지 확인합니다.
4. **폰트 내보내기**에서 필요한 포맷을 선택하고 검사한 뒤 저장합니다. Windows에 설치할 폰트는 TTF 또는 OTF를 선택하세요.

## AI는 필요할 때 켜세요

**설정 → AI 어시스트**에서 선택할 수 있으며, 처음에는 꺼져 있습니다.

| 선택 | 사용 방법 |
| --- | --- |
| 사용 안 함 | 직접 그리기와 폰트 내보내기를 사용합니다. |
| 로컬 AI | 처음 선택하면 모델을 자동으로 설치합니다(약 3.4GB 다운로드). 설치 후에는 인터넷이나 API 키 없이 사용할 수 있습니다. |
| OpenAI 호환 / Anthropic 호환 | 이용할 서비스의 API 주소·모델 이름·키를 입력합니다. 인터넷 연결이 필요하며 서비스 이용 요금이 발생할 수 있습니다. |

그림에 대해 상담하거나 새 후보를 만들 수 있습니다. 생성된 후보는 현재 그림과 비교한 뒤 **이 후보 채택**으로 적용합니다. API에 그림을 보낼지는 별도로 선택하며, API 키는 현재 Windows 계정으로 암호화해 저장합니다.

## 작업 저장과 화면 설정

작업은 이 PC에 자동 저장됩니다. 다른 곳에 보관하거나 옮길 때는 **프로젝트 → 프로젝트 사본 저장**을 사용하세요. 기본 저장 위치는 `%LOCALAPPDATA%/DoodleFont`입니다.

설정에서 표시 언어와 라이트·다크 테마를 바꿀 수 있습니다. 컴패니언은 드래그해 옮기고 우클릭으로 옵션을 엽니다. 입력창이 그림을 가리면 **접기**로 줄였다가 하단 상태바에서 다시 열 수 있습니다.

# 두들 폰트 · Doodle Font

문자와 문자열의 원문을 유지하면서 나만의 글리프를 그리는 **Windows용 Rust 네이티브 폰트 작업실**입니다. egui/eframe으로 화면을 직접 그립니다. 앱 실행과 빌드에 Node.js, Electron, Tauri, 웹뷰, Python이 필요하지 않습니다.

## 실행

`release/Doodle-Font.exe`를 실행합니다. 설치 없이 사용할 수 있습니다. Windows 10/11 x64와 OpenGL을 지원하는 그래픽 드라이버가 필요합니다.

작업은 `%LOCALAPPDATA%/DoodleFont/project.json`에 자동 저장됩니다. 이전 저장은 `project.backup.json`에 남습니다. 상단 **프로젝트 → 프로젝트 사본 저장**은 템플릿 원본·기준 버전·후보·이미지를 포함한 JSON 사본을 만듭니다. **새 프로젝트**를 누르면 기존 프로젝트를 `projects/`에 보관하고 새 프로젝트를 시작합니다. **열기…**로 사본과 백업을 다시 열 수 있습니다.

## 가볍게 시작하는 작업실

기본 Windows 제목 표시줄 대신 앱과 통합된 상단을 사용합니다. 상단을 드래그해 창을 옮기고 더블클릭해 최대화·복원하며, 오른쪽의 최소화·최대화·닫기 버튼과 창 가장자리 크기 조절을 사용할 수 있습니다. AI 처리 중에도 창 제어는 가능하며, 닫기를 누르면 진행 중 작업을 취소한 뒤 변경 사항을 저장하고 종료합니다.

일반 창에서는 네 모서리가 둥글고, 최대화·전체 화면에서는 반듯하게 채웁니다. 원래 크기로 돌아오면 둥근 모서리도 복원됩니다. Windows 11에서는 운영체제의 기본 곡선 처리를 사용하고, 해당 기능이 없는 Windows에서는 화면 배율에 맞춘 창 영역으로 모서리를 다듬습니다.

상단에는 현재 프로젝트 이름과 폰트 패밀리가 큰 글자로 항상 표시됩니다. 긴 이름은 줄여 표시하고 마우스를 올리면 전체 내용을 확인합니다. 탭 줄 오른쪽의 **프로젝트** 패널에서 이름을 바꿀 수 있으며 입력 중에는 열린 상태를 유지하고, 바깥 클릭이나 Esc로 닫습니다. **그리기·문장 미리보기·템플릿·설정**은 밑줄로 현재 화면을 표시하는 탭입니다.

왼쪽 문자 모음 선택 메뉴에서 글자를 고르고 바로 그립니다. 자주 쓰는 도구는 캔버스 위에, 상세 편집·복원·부품은 오른쪽 **레이어 · 속성**에 모았습니다. 사이드바의 화살표로 펼치거나 접으면 약 0.24초 동안 폭과 내용이 부드럽게 전환됩니다. 작은 보조 동작은 여백을 둔 텍스트 버튼으로 표시합니다. 템플릿 카드는 높이와 적용 버튼 위치를 맞추고, 긴 이용 조건·출처는 카드 안에서 스크롤합니다.

**화면** 메뉴 또는 **설정**에서 **시스템·라이트·다크**를 선택합니다. 기본은 시스템이며 Windows 테마 변경을 따릅니다. 컴패니언을 **마우스 오른쪽 버튼**으로 누르면 표현 방식·움직임 줄이기·나란히 비교 메뉴가 열립니다. 같은 옵션은 **설정 → 컴패니언**에도 있습니다. 테마와 컴패니언 옵션은 프로젝트와 별도의 `appearance.json`에 저장되어 다음 실행에 복원됩니다. **움직임 줄이기**에서는 사이드바도 즉시 전환합니다. 다크 모드에서도 그림의 원래 색상을 확인하는 종이와 폰트 미리보기는 밝게 유지합니다. 버튼은 마우스·키보드 포커스·선택에 따라 크기가 바뀌지 않습니다.

두들은 대기 중 두리번거리기·기지개·둥글게 흔들리기·네모 모양으로 쉬기를 번갈아 합니다. 커서를 움직이면 눈이 먼저 보고 고개와 몸이 따라옵니다. 생각·분석·그리기·색 고르기·설명·완료·확인 필요 상태마다 몸의 형태, 색, 기울기와 움직임이 달라집니다. 현재 자세와 속도를 이어받아 동작을 전환하며 **움직임 줄이기**에서는 상태를 나타내는 고정된 모양과 색만 표시합니다.

두들은 입력창 오른쪽의 독립된 플로팅 영역에 크게 표시됩니다. 창 크기에 따라 160~192 크기를 사용하며 입력창을 접어도 작아지지 않습니다. 처리 중에도 같은 자리에서 움직이고, 입력·편집 잠금과 작업 취소는 유지됩니다. 캐릭터와 입력창은 작업 영역의 크기를 줄이지 않습니다.

어시스트의 작은 잉크방울 **두들**은 숨쉬기·시선 이동·눈 깜박임, 처리 중·완료·오류 반응을 보여줍니다. ‘Grok Bot 스타일 이미지 생성’ 프로젝트에서 확인한 미니멀 얼굴 지침을 참고한 새 이미지이며, [coucou의 애니메이션 구조](https://github.com/Louis-CFM/coucou/blob/08393b657c79e99382eaf15185f480e6745997b0/NotchBuddy/Sources/CoucouKit/BotEngine.swift)를 참고해 Rust로 움직임을 구현했습니다. 이미지와 생성 프롬프트는 [assets/companion](assets/companion/README.md)에 보관합니다. 외부 애니메이션 실행기나 모델 호출 없이 움직이며, 앱이 포커스를 잃거나 움직임 줄이기를 켜면 연속 화면 갱신을 요청하지 않습니다.

컴패니언은 **벡터**를 기본으로 사용합니다. 컴패니언의 **원본 그림**은 PNG 몸체를 실시간으로 변형하고 벡터 눈을 합성합니다. 별도의 **벡터** 방식은 몸·머리·홍조·눈을 모두 곡선과 도형으로 그립니다. **컴패니언 우클릭 → 나란히 비교**에서 같은 동작을 비교하고 선택할 수 있으며, 선택은 다음 실행에도 유지됩니다. 원본은 은은한 질감, 벡터는 또렷한 윤곽이 특징입니다. 작은 표시에서 벡터의 CPU 그리기 준비 비용이 낮았으며, 큰 크기·높은 배율에서는 비용이 비슷했습니다. 정확한 수치와 측정 범위는 [컴패니언 비교](docs/COMPANION-RENDERERS.md)를 참고하세요.

**설정 → AI 어시스트**에서 **사용 안 함 / 로컬 AI / OpenAI 호환 / Anthropic 호환**을 선택합니다. 새 환경에서는 사용 안 함으로 시작하며 기존 연결 선택은 유지합니다. 사용 안 함에서는 입력 판단을 포함한 AI 요청과 프롬프트 창이 꺼지고, 저장한 API 연결 정보는 보존됩니다. 프로젝트 이름·폰트 패밀리와 자동 저장 위치는 상단 **프로젝트** 메뉴에서 확인하고 바꿉니다.

AI를 선택한 뒤 **획 다듬기·둥근 손글씨·균형 봐주기**를 고르면 요청과 모드가 채워집니다. 내용을 확인한 뒤 생성·상담 버튼으로 보냅니다. **접기**를 누르거나 캔버스에 그리기 시작하면 입력창이 약 0.28초 동안 하단 상태바로 줄어들어 들어갑니다. 상태바의 **어시스트 열기 ↑**로 다시 엽니다. 접힌 뒤에는 투명한 입력 영역도 남지 않으며 컴패니언의 위치와 크기는 유지됩니다. 움직임 줄이기에서는 즉시 접고 펼칩니다. 설정에 들어갈 때도 입력창을 접으며 긴 답변과 입력은 각 영역 안에서 스크롤합니다.

컴패니언을 **마우스 왼쪽 버튼으로 드래그**하면 작업 화면 안에서 원하는 곳으로 옮길 수 있습니다. 놓은 위치는 다음 실행에도 유지되며 창 크기에 맞춰 조정됩니다. **우클릭 → 기본 위치로 되돌리기**를 누르면 입력창 옆으로 돌아갑니다. 가볍게 클릭하는 반응과 우클릭 설정 메뉴는 그대로 사용할 수 있으며, AI 작업 중에는 위치 이동도 잠깁니다.

## 할 수 있는 일

- 라틴·확장 라틴, 한글 11,172자·옛한글 자모, 한국한자·일본한자 각각 20,992자, 가나·반각 가나, 기호·이모지, 공백·PUA 탐색. 목록은 화면에 보이는 행만 그리며 선택한 글리프만 작업 데이터로 만듭니다.
- 문장 붙여넣기와 자소 클러스터 추출. 표시 선택자·ZWJ·분해 악센트 원문 보존. 임의 문자열을 하나의 글리프에 매핑. 같은 코드포인트의 한국어·일본어 자형은 독립적으로 보관합니다.
- 펜·직선·네모·타원, 색·팔레트·불투명도, 레이어 순서·잠금·복제·이동·삭제, 획 보정, PNG/JPEG 가져오기, 선택적 실루엣 벡터화, 부품 재사용.
- 작성한 현대 초성·중성·종성 자모로 기본 한글 음절 조합 후 음절별 수정. 복합 모음·위치별 세밀한 조정은 각 음절 편집으로 처리합니다.
- 템플릿 원본 복원, 사용자 기준 저장·복원, 사용자 정의 해제·시스템 폰트 표시를 별도 명령으로 제공. 관련 변형 복사는 명시적으로 선택한 대상에만 적용됩니다.
- 미작성·의도적 빈칸·미지원·시스템 표시 구분. 공백 폭 편집. 탭·줄바꿈·ZWJ 자체는 확인 전용입니다.
- 제공자·버전·출처·이용 조건과 표시·편집·폰트 포함·재배포·AI 전송 권한을 저장. 부품을 섞어도 출처와 제한을 유지합니다. Apple/Samsung 그림은 동봉하지 않습니다. 기본 세 그림은 앱에서 만든 CC0 원본입니다.
- 로컬 또는 OpenAI/Anthropic 호환 API로 그림 상담과 벡터 후보 생성. AI 창은 작업 영역의 크기를 줄이지 않고 하단에 겹쳐 뜹니다. 긴 응답과 여러 줄 입력은 각각 제한된 높이 안에서 스크롤하며, 접기/펼치기로 그림을 넓게 볼 수 있습니다. 처리 중 상태·경과 시간·취소를 표시하고 화면 전환·마우스·단축키·대화상자 편집을 잠그며 완료·오류·취소 후 해제합니다. API 연결은 Windows 계정으로 암호화해 저장하고 후보는 직접 채택합니다.

## 내장 로컬 AI

**현재 버전은 0.1.0입니다. 버전은 사용자가 명시적으로 요청할 때만 변경합니다.**

**설정 → AI 어시스트 → 로컬 AI**를 선택하면 모델이 없는 경우 자동으로 설치를 시작합니다. 이미 설치됐다면 다시 설치하지 않습니다. 설치 중에는 진행률과 취소 버튼을 표시하며, 취소·실패 후에는 **설치 다시 시도**로 이어받습니다. 앱을 다시 열었다는 이유만으로 다운로드를 재시작하지 않습니다. 설치 위치·부족한 파일·**설치 파일 검증 · 복구**는 **모델 정보 · 설치 관리**를 펼쳐 확인합니다. SHA256 검증을 통과한 파일은 재사용하며 설치 상태는 자동으로 갱신됩니다.

명령줄 설치도 유지합니다: `pwsh -File scripts/install-local-ai.ps1`. 약 3.4GB를 내려받으며 모델 리비전·실행기 버전과 SHA256을 고정해 검사합니다. 설치 후에는 인터넷과 API 키 없이 사용할 수 있습니다. 설치 위치는 `%LOCALAPPDATA%/DoodleFont/ai`이며 `DOODLE_AI_DIR`로 바꿀 수 있습니다. 기존 설치의 Gemma 파일은 그대로 재사용합니다. EmbeddingGemma 파일은 더 이상 요구하거나 실행하지 않으며, 사용자의 기존 파일을 자동 삭제하지 않습니다.

- **Gemma 4 E2B Q4 단독**: 프롬프트와 드로잉 영역 PNG를 직접 읽고 한국어 상담 또는 편집 가능한 벡터 후보를 만듭니다. 임베딩 단계와 참고 그림 유사도 표시는 제거했습니다.
- **정확한 글자 생성**: 로컬 AI는 요청을 고딕·명조·손글씨, 굵기·너비·기울기·모서리·간격으로 해석하고, Rust 엔진이 함께 제공되는 공개 글꼴의 정확한 자형으로 벡터를 구성합니다. 작은 모델이 글자의 좌표를 임의로 만들어 획을 빠뜨리는 문제를 줄입니다. 한글·영문·가나·한자, 결합 문자와 한국어/일본어 자형을 셰이핑하며 내부 빈 공간도 보존합니다. “현재 그림을 유지하고 획 굵기를 70으로 통일해줘”처럼 요청하면 직접 그린 선의 형태를 보존해 보정합니다.
- 기본 자형은 **Noto Sans CJK / Noto Serif CJK / Single Day**이며 SIL OFL 1.1 조건으로 포함합니다. 후보에 출처를 기록하고 채택·저장·출력까지 전달합니다. 해당 자형을 사용한 출력 폰트에는 OFL 조건이 포함됩니다. Windows 시스템 폰트의 윤곽을 복제하지 않습니다. 손글씨 글꼴에 없는 문자는 고딕 자형을 사용하고 안내합니다. 고딕·명조는 가변 굵기를 지원하며, 손글씨의 기본 획 굵기는 제공 글꼴의 형태를 따릅니다.
- 앱은 Rust이며 Gemma 추론에는 네이티브 C++ 실행기 **llama.cpp b11531**을 사용합니다. 숨겨진 프로세스가 임의의 localhost 포트와 매번 새 인증 키로 실행됩니다. 웹 UI는 끄고 Gemma만 로드하며, 완료·취소 시 프로세스와 메모리를 정리합니다. 기본은 CPU 6스레드/8K 문맥입니다.
- **공통 크기와 정렬**: 편집 화면·내장 AI·API에 같은 1000×1000 좌표와 글자 폭을 사용합니다. 새 후보는 획 두께를 포함한 실제 그림의 좌우 여백을 균등하게 맞추며, 영역을 채우기 위해 크기를 늘리거나 가로만 누르지 않습니다. 좌우 가이드는 최소 여백을 위한 한계선이며 글자가 반드시 닿아야 하는 선이 아닙니다. 보통 최소 여백은 각각 80이며 아주 좁은 글자 폭에서는 줄입니다. 자연스러운 비율로 들어가지 않는 후보는 폭·스타일 조정을 안내합니다.
- **글자별 비율 안내**: AI에 대상 글자의 내장 기본 자형에서 구한 참고 폭·높이·위아래 위치를 전달합니다. I는 가늘게, M은 넓게, 소문자와 구두점은 제 크기를 유지하도록 안내하며 참고 치수는 스타일에 따라 달라질 수 있습니다. 내장 AI의 폭·자간은 사용자가 별도로 요청하지 않으면 기본값을 사용합니다. 대문자 높이 200, 기준선 800, 하강 한계 960을 공유하며 g·j·p·q·y의 아래 획은 기준선 밑에 남깁니다. API 후보도 아래 획이 빠졌거나 영역을 벗어나면 다시 생성을 안내합니다. 기존 그림 보정이나 명시적인 위치 요청은 우선하며 저장된 그림을 일괄 재배치하지 않습니다.
- 이미지 입력은 같은 가이드라인을 포함한 현재 글리프의 512×512 PNG입니다. AI에 픽셀과 폰트 좌표의 비율, 가이드가 그림의 획이 아니라는 점도 전달합니다. 다른 앱 화면을 캡처하지 않습니다. API 모드에서는 그림 전송 체크박스를 켰을 때만 PNG와 벡터를 보냅니다. AI 사용 권한이 없는 원본·부품은 로컬에서도 사용하지 않습니다.

**글리프 자동 그리기:** 글자를 고른 뒤 하단에서 **후보 만들기 → 그림 생성**을 누릅니다. 생성이 끝나면 **현재 그림 / 선택한 AI 후보** 비교 화면이 자동으로 열립니다. 후보를 골라 **이 후보 채택**을 누르면 편집 화면에 적용하며 실행 취소도 가능합니다. 창을 닫아도 후보는 보존되고, 하단의 **저장된 후보 N개 보기 · 채택** 또는 글리프 속성 상단의 **AI 후보 N개 보기 · 채택**에서 다시 열 수 있습니다. 설정 화면에서 생성해도 같은 비교 화면이 열립니다. 설명만 반환되거나 보이는 도형이 없는 응답은 생성 성공으로 처리하지 않습니다.

`cargo run --locked --bin verify_ai`로 Gemma 단독의 실제 로컬 텍스트·이미지 입력과 답변을 검증할 수 있습니다. `-- --generate`는 그림 후보 생성을 검증합니다. 자세한 모델 사양은 [Gemma 4 E2B](https://huggingface.co/google/gemma-4-E2B-it)에 있습니다.

`cargo run --locked --bin verify_quality -- artifacts/quality-current`는 실제 내장 모델로 A·B·가·한·あ·永를 생성하고 요청·응답·미리보기·소요 시간을 보관합니다. 뒤에 `--styles`를 붙이면 얇은 명조체·손글씨·기존 획 보정을 검증하고, `--layout`은 H·x·g의 정렬·소문자 크기·하강 획을 검사하며 가이드가 포함된 이미지도 보관합니다. 글자 생성은 제공 자형을 활용한 스타일 변환이며 자유로운 새 서체의 학습이나 모든 그림문자의 정확한 재현을 보장하지 않습니다. 그림문자는 기존 벡터 생성 경로를 사용합니다.

## 입력 판단 AI · 공통 옵션

**설정 → 내장 판단 AI 사용** 체크로 켜고 끕니다. 기본은 꺼짐이며 처음 켤 때 Needle 3가 없으면 약 37MB를 자동 설치합니다. 설치된 경우 바로 사용하고, 실패·취소 후에는 **설치 다시 시도**를 제공합니다. 모델 설명·검증·복구는 **판단 AI 자세히** 안에 있습니다. 생성 AI 선택과 독립된 입력 보조 옵션으로 로컬 Gemma·OpenAI 호환·Anthropic 호환에 공통 적용되며, 생성 AI가 **사용 안 함**이면 판단도 실행하지 않습니다. 판단 옵션은 `ai-options.json`에 저장하며 API 키는 포함하지 않습니다. 설치 위치는 로컬 AI 폴더 아래 `decision/`이며 `DOODLE_NEEDLE_DIR`로 별도 지정할 수 있습니다.

입력 직후 Needle에 **사용자 텍스트만** 전달하고, 생성 AI 호출 직전에 Rust가 판단과 실행 조건을 확인합니다. 이미지·API 키·프로젝트 전체는 Needle에 보내지 않습니다. 상담/생성 모드·대상 문자·연결 제공자·이미지 전송 동의는 판단 모델이 변경할 수 없습니다.

Needle의 기존 판단 결과는 컴패니언 동작 선택에도 사용합니다. 검증된 획 수정·색 변경·분석·생성 요청에 맞는 동작을 고르며, 프레임 생성이나 대기 동작을 위한 추가 추론은 없습니다. Needle를 끄거나 판단에 실패해도 상담/그리기와 실제 완료·오류 상태에 맞는 기본 애니메이션은 작동합니다.

신뢰도 0.8 이상, 억제/근거 오류 없음, 단일 작업이며 사용자가 명시한 값과 일치하는 제한된 획 굵기/색상 명령은 Rust가 바로 **후보**로 구성합니다. 예: `Set the stroke width to 70.`. 채택은 기존 비교 화면에서 직접 합니다. 여러 작업·부정문·잠긴 레이어·이미지 레이어·윤곽 굵기 변경은 빠른 처리 대상에서 제외합니다. 상담은 항상 선택한 생성 AI가 담당합니다.

미설치·오류·12초 시간 초과·낮은 신뢰도·지원 밖의 요청은 원문을 선택한 생성 AI로 전달합니다. **취소는 다음 AI로 넘기지 않고 작업 전체를 중단합니다.** Needle는 전용 Windows 실행기를 잠깐 실행하며 UTF-8 localhost 통신을 사용합니다. 완료·오류·취소 시 프로세스를 종료합니다. Node/Python 런타임은 필요하지 않습니다.

현재 기본 Needle의 한국어 정확도는 제한적입니다. 실제 시험에서 낮은 신뢰도와 잘못된 호출, 잘못된 형식의 응답이 관찰됐고 모두 원문 전달 경로로 처리합니다. 판단을 켠다고 모든 요청이 빨라지거나 글자 정확도가 보장되는 것은 아닙니다. 기본 꺼짐 상태에서 Gemma 단독 또는 선택한 API를 그대로 사용할 수 있습니다.

`cargo run --locked --bin verify_decision`은 Needle를 설치/검증한 뒤 실제 판단 결과와 실패를 `artifacts/decision-live.json`에 기록합니다. `pwsh -File scripts/ui-qa.ps1 -DecisionAi`는 판단 모델과 Gemma가 설치된 환경에서 외부 API 호출 없이 빠른 후보 생성, 한국어 요청의 Gemma 전달을 실제 UI로 검증합니다. 공식 자료: [Needle 3](https://huggingface.co/Cactus-Compute/needle3).

## API 연결 저장

API 제공자를 선택한 뒤 **연결 설정**을 펼치면 API 주소·모델 이름·키를 입력할 수 있습니다. 입력은 자동 저장하며 다음 실행에 복원합니다. **연결 설정 저장**은 즉시 저장하고, **저장된 키 삭제**는 현재 제공자·주소의 키만 지웁니다. 주소를 바꾸면 해당 주소에 저장한 키만 표시합니다.

**연결 테스트**는 현재 API와 모델에 짧은 텍스트 요청을 보내 응답을 확인합니다. 프로젝트·그림은 보내지 않으며 제공자의 API 사용량이 발생할 수 있습니다. 성공·오류·취소 결과를 설정에 표시하며 이미지 입력이나 그림 생성 품질까지 검사하는 기능은 아닙니다. 스타일과 실제 그림 생성은 **생성 테스트…** 메뉴의 별도 창에서 선택한 글자로 확인합니다. 결과는 바로 적용하지 않고 기존 후보 비교 화면에서 직접 채택합니다.

연결 정보는 `%LOCALAPPDATA%/DoodleFont/ai-connections.dat`에 Windows DPAPI로 암호화합니다. `DOODLE_DATA_DIR`을 지정했다면 해당 폴더를 사용합니다. Windows에 로그인된 계정을 이용하며 별도의 앱 비밀번호나 지문을 요구하지 않습니다. 임시 저장 파일도 암호화하며 프로젝트·폰트·판단 옵션 파일에는 키를 넣지 않습니다. 읽기나 저장이 실패하면 AI 연결 화면에 표시하며 평문으로 대신 저장하지 않습니다.

DPAPI는 앱별 격리 금고가 아닙니다. 같은 Windows 사용자로 실행되는 다른 프로그램의 접근까지 막는 기능은 아니며, 다른 PC나 Windows 계정으로 옮길 때는 연결 정보를 다시 입력해야 할 수 있습니다. [Microsoft DPAPI 설명](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata).

## 폰트 출력

**폰트 내보내기**에서 **파일 포맷**과 **글자 표현 방식**을 각각 선택합니다. 전체·현재 문자 모음·문장에 필요한 글리프, 통합 또는 한국어·일본어 자형, 문자 모음별 ZIP 분할을 함께 선택할 수 있습니다. 저장 창의 확장자와 ZIP 안의 파일도 선택한 포맷을 따릅니다.

| 파일 포맷 | 용도와 포함 내용 |
| --- | --- |
| TTF | 컴퓨터 설치·문서용. TrueType 윤곽선 |
| OTF | 컴퓨터 설치·디자인 작업용. 실제 CFF Type 2 윤곽선과 OpenType 테이블 |
| WOFF2 | 웹사이트용. TrueType 기반 폰트를 Brotli로 압축 |
| WOFF | 웹사이트용. TrueType 기반 폰트를 zlib으로 압축 |

네 포맷 모두 **단색·컬러·비트맵**을 지원합니다. 단색은 이미지를 64×64 알파 실루엣으로 변환합니다. 컬러는 벡터 레이어의 COLR v0/CPAL을 포함하고, 이미지가 있으면 전체를 비트맵으로 출력합니다. 비트맵은 512 ppem PNG와 sbix를 사용하며 그림이 1000×1000 작업 영역으로 잘립니다. 컬러·비트맵 표시 지원은 사용하는 앱과 브라우저에 따라 다릅니다. 웹폰트는 웹페이지에서 사용하는 파일이며 Windows에 설치하려면 TTF 또는 OTF를 선택하세요.

모든 포맷은 Rust 안에서 생성하며 별도 변환기나 다운로드가 필요하지 않습니다. WOFF2는 표준의 무변환(null transform) 테이블 압축을 사용합니다. CFF의 글리프별 charstring 용량 한계를 넘는 매우 복잡한 그림은 오류로 안내하며 레이어를 단순화하거나 TTF·웹폰트로 출력할 수 있습니다.

단일 문자에는 Windows 호환용 cmap format 4와 전체 유니코드용 format 12를 함께 넣고, 표시 선택자에는 format 14, 문자열에는 GSUB `rlig`, 지역별 한자에는 `locl`을 생성합니다. 레이어·대체 자형·시퀀스 입력 부품까지 포함해 65,535개 한계를 검사합니다. BMP 매핑은 연속 구간과 글리프 배열을 조합해 압축하며 표의 용량 한계를 넘으면 분할 출력을 안내합니다. 출력 옆에 검사 보고서를 저장하며 ZIP에도 보고서를 포함합니다.

Windows에서는 TTF·OTF의 **출력 전 검사와 파일 저장 모두 실제 Windows 글꼴 로더로 검증**합니다. 검증용 글꼴은 앱 프로세스 안에서 잠깐 읽고 해제하며 시스템에 설치하지 않습니다. 이전 실행 파일에서 내보낸 TTF·OTF가 올바르지 않은 파일로 표시됐다면, 갱신된 실행 파일에서 프로젝트를 열어 다시 내보내세요.

문장 미리보기는 프로젝트 그림과 시스템 폰트 대체를 구분합니다. **TTF 생성·검사**는 실제 생성한 파일을 다시 파싱하고 Rustybuzz로 셰이핑한 뒤 윤곽·컬러·비트맵을 렌더링합니다. 시스템 글리프를 폰트에 복제하지 않습니다. 외부 앱에서의 `rlig`, `locl`, variation selector, 컬러 지원은 앱마다 다르며 모든 앱의 이모지 변경을 보장하지 않습니다. 시퀀스에 필요한 단일 문자가 미작성인 경우 빈 입력 글리프가 포함되며 보고서에 표시됩니다.

시스템 대체는 현재 기기의 Malgun Gothic, Yu Gothic/Meiryo, Segoe UI Emoji 등을 사용합니다. 앱의 자체 셰이핑·렌더링이므로 다른 Windows 앱과 픽셀 단위로 같음을 보장하지 않습니다. 시스템 글꼴은 배포 파일에 포함하지 않습니다.

Rust MSVC 툴체인과 Visual Studio C++ Build Tools/Windows SDK가 필요합니다.

```powershell
cargo run --locked
cargo test --locked
cargo run --release --locked --bin verify -- --large
pwsh -File scripts/ui-qa.ps1
# 설치된 로컬 모델로 실제 그림 생성과 후보 창까지 확인

pwsh -File scripts/package.ps1
```

`verify`는 TTF·OTF·WOFF·WOFF2 각각의 단색·컬러·비트맵 파일 12개, TTF·OTF 렌더링 PNG, 검사 프로젝트 및 선택적인 53,156개 글리프 부하 자료를 `artifacts/verification/`에 만듭니다. 큰 부하 자료는 폭과 지역별 치환을 검증하는 빈 글리프 데이터이며 복잡한 그림 처리 속도를 대신하지 않습니다. 개발용 `python scripts/verify-font-formats.py`는 fontTools와 Brotli로 모든 테이블·CFF 글자 폭·웹폰트 복원을 독립 검증하고 브라우저 확인용 `browser-fonts.html`을 생성합니다. Python은 이 독립 검증에만 필요합니다. `pwsh -File scripts/ui-qa.ps1 -ExportOnly`는 실제 포맷 선택·출력 전 검사·작은 창을 검증합니다.

UI QA는 테스트 전용 빌드에서 각 화면을 실제 GPU로 렌더링하고, 포인터 입력으로 그리기·실행 취소·다시 실행·원본 보존·디스크 저장을 검증합니다. 일반 배포 빌드에는 QA 입력 경로가 포함되지 않습니다. AI 계약 테스트는 로컬 모의 서버로 두 API 방식과 잘못된 응답을 검사합니다. 실제 외부 서비스 호출은 사용자가 키·모델을 설정한 뒤 확인해야 합니다.

프로젝트는 최대 150,000 작업 글리프, 저장 파일은 64MB, 이미지 원본은 4096×4096/8MB, 실행 취소는 30회 또는 약 24MB로 제한합니다. 원본 파일·백업이 손상된 경우 자동 저장을 멈추고 기존 파일을 보존합니다.
